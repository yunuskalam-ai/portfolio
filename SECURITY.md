# Security Policy

## Supported versions

The latest commit on `main` is the supported version.

## Reporting a vulnerability

Email **yunuskalam@gmail.com** with:

- a description of the issue,
- affected URL or file,
- reproduction steps,
- impact assessment.

Please do not open a public issue for undisclosed vulnerabilities. You can expect an acknowledgement within 7 days.

## Scope

This repository is a static portfolio. The main security considerations are:

- no server-side code or secrets,
- no third-party runtime dependencies,
- no external fonts, trackers, or analytics,
- Content Security Policy and referrer policy declared in page metadata.
